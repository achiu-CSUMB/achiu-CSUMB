Lesson 4: Add External Stylesheet
Question:
Why is an external stylesheet usually easier to maintain than many inline styles?

Student response:
An external stylesheet centralizes all styling in one file, so a design change only needs to be made once and automatically applies to every element and page that uses it.

Lesson 6: Create the About page
Question:
Explain the difference between an ID selector and a class selector in CSS. When would you use each one?

Student response:
An ID selector targets the one element whose id attribute matches. A class selector targets every element whose class attribute contains that class.
